# Simple introduction (en)
This is a project to test the time-taken in different programming language running, and there was only a part - Calculations at present.  
You need a compiler to compile the C or C++ programming. (I recommend you to use 
[MSVC (Only Windows) ](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170), 
[MinGW (GCC/G++) ](https://www.mingw-w64.org) or [Clang](https://clang.llvm.org)).
Also, you need download [Java](https://www.java.com), [Python](https://www.python.org) and [Node.js](https://nodejs.org) 
to run other programming.
